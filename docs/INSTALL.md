# 설치 안내

## GitHub Releases에서 설치

1. 최신 릴리스의 `Wikey-버전.dmg`를 내려받습니다.
2. DMG를 열고 Wikey를 Applications 폴더로 드래그합니다.
3. 응용 프로그램 폴더의 Wikey를 엽니다.

GitHub Releases의 정식 DMG는 Developer ID로 서명되고 Apple 공증을 완료했습니다. 처음 실행하면 Wikey가 할 수 있는 일과 기본 사용 순서를 소개한 뒤, 필요한 기능의 권한을 선택할 수 있습니다.

## 권한 켜기

Wikey의 **설정 → 권한**에서 필요한 기능만 켭니다.

- **손쉬운 사용:** 앱 창 배치와 자동 붙여넣기
- **입력 모니터링:** 두 단계 단축키

시스템 설정에서 권한을 바꾼 뒤 Wikey로 돌아오면 상태가 자동 갱신됩니다. 계속 꺼짐으로 보이면 Wikey를 완전히 종료한 뒤 다시 실행하세요.

앱을 다시 빌드하거나 교체하면 macOS가 새 앱으로 인식해 권한을 다시 요청할 수 있습니다.

## 자동 업데이트

Wikey 1.1.0부터 앱을 실행하는 동안 하루에 한 번 새 버전을 확인합니다. 새 버전이 있으면 Wikey 안에서 다운로드하고 설치한 뒤 다시 실행할 수 있습니다.

- 직접 확인: 메뉴 막대 또는 앱 메뉴의 **업데이트 확인…**
- 설정 변경: **설정 → 업데이트**
- 자동 다운로드는 기본으로 꺼져 있으며 사용자가 선택할 수 있습니다.

Wikey 1.0.0에는 업데이트 기능이 없기 때문에 1.1.0 DMG를 한 번 직접 설치해야 합니다. 그 다음 버전부터는 앱 안에서 업데이트할 수 있습니다.

## 소스에서 실행

```sh
git clone https://github.com/movvgli/Wikey.git
cd Wikey
./script/build_and_run.sh
```

빌드된 앱은 `dist/Wikey.app`에 생성됩니다.
