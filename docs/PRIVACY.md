# 개인정보 보호

Wikey는 별도의 Wikey 계정이나 서버 없이 동작합니다. 선택 기능인 iCloud 동기화에는 사용자의 Apple 계정과 iCloud Drive가 필요합니다.

- 워크플로, 템플릿과 레이아웃은 사용자의 Mac에 저장됩니다.
- 분석 도구, 광고 SDK와 원격 추적 기능을 포함하지 않습니다.
- 자동 업데이트 확인을 켜면 GitHub의 공개 업데이트 피드에 접속합니다. 워크플로, 템플릿, 클립보드 내용은 이 요청에 포함하지 않습니다.
- 현재 클립보드 내용과 기록한 키 입력을 네트워크로 전송하지 않습니다. 동기화를 켜면 저장한 단축키 조합과 템플릿 등 아래의 설정 데이터가 iCloud Drive에 저장됩니다.
- 입력 모니터링은 사용자가 지정한 두 단계 단축키를 판별하는 데만 사용합니다.
- 손쉬운 사용 권한은 창 배치, 사용자가 요청한 붙여넣기·Enter 입력, 두 단계 단축키의 두 번째 키가 다른 앱에 입력되지 않도록 처리하는 데 사용합니다.

Wikey가 여는 웹사이트와 외부 앱에는 해당 서비스의 개인정보 보호정책이 적용됩니다.

## 선택적 iCloud 동기화 (1.2.7 시험 기능)

실제 두 Mac 간 전송은 아직 미검증입니다. 사용 전 로컬 백업을 권장합니다.

- 기본값은 꺼짐입니다. 설정에서 전송 항목 안내에 동의하고 iCloud Drive의 개인 폴더를 직접 선택해야 시작합니다. 각 Mac에서 같은 폴더를 선택합니다.
- 워크플로, 앱·레이아웃 단축키, 템플릿의 텍스트·서식, 레이아웃, 동작에 연결한 이미지·파일 사본을 포함합니다. 템플릿이나 파일 안에 개인 정보가 있다면 함께 저장됩니다. 백업을 볼 수 있는 사람은 내용도 읽을 수 있으므로 공유 폴더를 선택하지 마세요. Wikey가 별도로 백업 파일을 암호화하지는 않습니다.
- 첨부 파일의 원래 로컬 경로는 이식 가능한 식별자로 바꿉니다. 사용자 이름 대신 무작위 Mac 식별자를 사용합니다. 손쉬운 사용·입력 모니터링 권한, 로그인·업데이트 설정, 폴더 접근 권한, 이 Mac의 모니터 매핑은 동기화하지 않습니다.
- Wikey 서버, 소개 사이트, GitHub로 개인 설정을 업로드하지 않습니다. Apple의 iCloud Drive가 업로드·다운로드를 처리하며 실제 전송 시간은 인터넷과 iCloud 상태에 따라 달라집니다. 앱의 '폴더 확인'은 다른 Mac까지 전송됐다는 보증이 아닙니다.
- 동시에 수정한 설정은 두 버전을 보관하고 사용자가 전체 설정을 선택합니다. 편집 화면 활성화 또는 워크플로 실행 중에는 자동 적용을 미룹니다. 적용 전에는 현재 설정을 로컬 백업합니다.
- 동기화를 꺼도 이미 저장한 iCloud 파일과 `Application Support/Wikey/Backups`의 로컬 백업은 지우지 않습니다. 백업은 자동 만료되지 않습니다. 완전히 제거하려면 모든 Mac에서 동기화를 끈 뒤 Finder에서 해당 백업을 삭제해야 합니다.
- 첨부 파일은 각각 20MB, 백업 데이터는 총 50MB까지 지원합니다. 폴더·심볼릭 링크 첨부와 없는 파일은 오류로 안내하며 불완전한 설정으로 덮어쓰지 않습니다.

## 소개 사이트

- 사이트의 기능 화면은 설명을 위해 만든 가상 예시입니다. 개인 워크플로, 실제 템플릿 내용이나 설치 앱 목록을 읽거나 표시하지 않습니다.
- 사이트에는 별도의 분석 SDK, 광고, 회원가입이나 개인 설정 업로드 기능이 없습니다. 브라우저에는 밝은/어두운 화면 선택만 저장하며 저장이 차단되어도 사용할 수 있습니다.
- 다운로드·문서 링크를 누르면 GitHub로 이동합니다. 호스팅 제공자의 기본 접속 처리는 해당 제공자의 정책을 따릅니다.

문제를 보고할 때는 템플릿 내용, 창 제목, 앱 목록 등 개인 정보가 포함될 수 있는 화면과 로그를 먼저 확인해주세요.
