# Wikey 소개 사이트

공식 주소: https://movvgli.github.io/Wikey/

GitHub Pages는 `main`의 `website/` 변경을 자동 배포합니다.
`.github/workflows/pages.yml`에서 빌드와 개인정보 검사를 통과한
`website/dist/client`만 게시합니다. 앱 소스, 사용자 설정, 서버 코드나
Sites 설정 파일은 사이트 배포 파일에 포함하지 않습니다.

사이트 내용은 `website/src/`에서 수정합니다. 설명용 가상 예시만 사용하고
실제 워크플로·템플릿·개인 앱 목록이 담긴 캡처는 추가하지 않습니다.

기존 Sites 설정은 복구용으로 보존하지만 기본 배포 경로는 GitHub Pages입니다.
앱 설치 파일과 자동 업데이트 피드의 배포 경로는 변경하지 않습니다.
