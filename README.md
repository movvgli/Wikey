<h1 align="center">Wikey</h1>

<p align="center">
  반복하는 일을 단축키 하나로 끝내는 macOS 워크플로 앱
</p>

Wikey는 앱 실행, 웹사이트 열기, 문구·이미지·파일 붙여넣기와 창 배치를 원하는 순서로 연결하는 macOS 앱입니다. 워크플로뿐 아니라 앱과 레이아웃에도 단축키를 지정할 수 있습니다.

모든 워크플로와 템플릿은 외부 서버로 전송하지 않고 사용자의 Mac에 저장됩니다.

## 빠르게 시작하기

1. [최신 릴리스](https://github.com/movvgli/Wikey/releases/latest)에서 `Wikey-버전.dmg`를 다운로드합니다.
2. Wikey를 **응용 프로그램** 폴더로 옮기고 실행합니다.
3. 첫 실행 안내에서 핵심 기능을 살펴보고, 사용할 기능에 필요한 권한만 켭니다.
4. **앱**에서 자주 여는 앱에 단축키를 지정하거나, **새 워크플로**에서 여러 동작을 연결합니다.
5. 처음 만든 플로우는 테스트용 문서에서 실행해 순서와 입력 대상을 확인합니다.

1.2.6부터 macOS 14 이상에서 사용할 수 있습니다. Apple Silicon·Intel용 빌드와 최소 OS 검증을 통과했으며, 실제 macOS 14·Intel 기기의 실행 검증은 아직 남아 있습니다. 정식 배포에는 Developer ID 서명과 Apple 공증을 확인한 DMG를 사용하며, 버전별 배포 상태는 [릴리스 노트](https://github.com/movvgli/Wikey/releases)에서 확인할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 워크플로 | 동작을 순서대로 실행하고, 이미 만든 다른 워크플로를 연결합니다. |
| 전역 단축키 | 한 번 또는 두 단계 입력을 지원하며, 워크플로·앱·레이아웃 간 충돌을 안내합니다. |
| 앱 | 설치된 앱을 검색하고, 목록에서 바로 열거나 단축키를 지정·해제합니다. |
| 웹사이트 | URL을 기본 브라우저로 엽니다. |
| 템플릿 | 서식·링크·목록·인라인 이미지가 있는 문구를 저장하고, 동작 설정에서 붙여넣을 템플릿을 선택합니다. 템플릿 삭제도 지원합니다. |
| 이미지와 파일 | 여러 이미지나 파일을 골라 대상 앱에 붙여넣습니다. |
| 키 입력과 대기 | Enter, Shift + Enter와 0.1–30초 대기를 동작 사이에 넣습니다. |
| 창 레이아웃 | 연결된 모니터에 전체, 1/2, 1/3, 2/3와 사분면으로 창을 배치합니다. 레이아웃만 실행하는 단축키도 지정합니다. |
| 실행 상태와 중지 | 현재 동작과 대기 중인 실행을 확인하고, 중지 버튼으로 실행과 대기열을 취소합니다. |
| 빠른 실행 | 메뉴 막대에서 워크플로를 실행하고 Mac 로그인 시 자동으로 준비합니다. |
| 자동 업데이트 | 앱 안에서 새 버전을 확인하고 다운로드해 설치합니다. |

한 동작이 실패하면 해당 워크플로의 나머지 동작을 중단하고 실패한 위치를 알려줍니다. 예를 들어 대상 앱을 열지 못한 뒤에 붙여넣기나 Enter가 계속 실행되지 않도록 합니다. 이미 완료한 동작을 되돌리지는 않습니다.

붙여넣기와 창 크기 변경은 대상 앱의 지원 범위에 따라 달라집니다. 첨부 처리 시간이 필요한 앱에서는 Enter 전에 **잠시 기다리기**를 추가하세요. 대기 시간만으로 파일 업로드 완료를 판별하지는 않으므로, 메시지를 보내는 플로우는 전송하지 않는 테스트 화면에서 먼저 확인하는 것이 좋습니다.

## 권한과 개인정보

Wikey는 사용하는 기능에 필요한 macOS 권한만 요청합니다.

| 권한 | 사용하는 기능 |
| --- | --- |
| 손쉬운 사용 | 창 이동·크기 변경, 붙여넣기·Enter 입력, 두 단계 단축키의 두 번째 키가 다른 앱에 입력되지 않도록 처리 |
| 입력 모니터링 | 두 단계 단축키의 두 번째 키 감지 |

한 번에 누르는 단축키로 앱이나 웹사이트를 여는 기능과 클립보드 복사는 위 권한 없이 사용할 수 있습니다. 붙여넣기·키 입력·창 배치는 손쉬운 사용 권한이 필요하며, 두 단계 단축키에는 두 권한이 모두 필요합니다. 자세한 내용은 [개인정보 보호 안내](docs/PRIVACY.md)를 확인하세요.

## 업데이트

Wikey는 실행 중 하루에 한 번 새 버전을 확인합니다. **Wikey → 업데이트 확인…** 또는 **설정 → 업데이트**에서 직접 확인할 수 있으며 자동 다운로드 여부는 사용자가 선택합니다.

## 개발

필요 환경:

- 사용하는 Xcode 버전이 지원하는 macOS (앱 실행 대상은 macOS 14 이상)
- Xcode와 Swift 6 도구 체인
- Xcode 프로젝트 재생성 시 [XcodeGen](https://github.com/yonaskolb/XcodeGen)

```sh
./script/build_and_run.sh
swift test
xcodegen generate
```

배포 패키지 제작과 공증 절차는 [배포 안내](docs/DISTRIBUTION.md)에 정리되어 있습니다.
